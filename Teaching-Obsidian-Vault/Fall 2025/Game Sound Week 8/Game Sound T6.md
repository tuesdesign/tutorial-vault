# Why use interactive audio?

## The most basic and overarching reason is to increase the 'juice' of your game <!-- element class="fragment" -->

### Whether we are conscious of it or not, when an element in a game reacts to our actions, we are more immersed. <!-- element class="fragment" -->

###  This can be tied to the psychological concept of operant conditioning: <!-- element class="fragment" -->

![[stormcastle-tv.gif]]<!-- element class="fragment" -->
https://www.youtube.com/watch?v=MGpFEv1-mAo <!-- element class="fragment" -->

---
## What sorts of behaviors can we enforce with interactive audio?

### When we design games, we want to guide the player towards certain actions.  <!-- element class="fragment" -->

### For example, in a game about speedrunning, we want to encourage the player to go fast. <!-- element class="fragment" -->

### When I designed the interactive music for Moonset, I added new instrument stems as the player went faster<!-- element class="fragment" -->

![[stormcastle-tv.gif]] <!-- element class="fragment" -->

https://www.youtube.com/watch?v=Fo476ePbalE<!-- element class="fragment" -->

---
## We can even make this a core element of the game
### Games with rhythm elements often use interactivity to indicate how well the player is doing, or to describe aspects of the game state.<!-- element class="fragment" -->
