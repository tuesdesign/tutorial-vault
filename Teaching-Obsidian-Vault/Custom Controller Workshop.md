# Software, Firmware, and Hardware 
![[Pasted image 20260613041200.png | 300]]
Software is a set of instructions that make up behaviors, such as playing a game

Hardware is physical components, such as a game console

Firmware is software that makes hardware function, especially connected hardware such as controllers.
