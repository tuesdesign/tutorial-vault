Input and Output
I wanted to start here because although we have an intuitive idea of what these mean, they are the most important things we consider when we are designing or using a controller, or anything else that a person uses and interfaces with.
	From the perspective of a game controller - picture of someone using a game controller
At a high level, input is something you *do* , an action that is performed. You can press a button. To be more specific, an input is something that we can detect, which could be pressing a button, or it could be strumming a guitar or waving your arms around or even blinking. Output is anything that we make happen as a result. I press the A button (input), and as a consequence, Mario jumps. 
 Anything that happens in between these, we can call the "processing" layer. So to use the same example, that notably includes the game controller, but also the game itself, and anything that sits in between those things, like the game console or computer, and all the code that makes these things work.


Hardware
When I say hardware, I am referring to physical items capable of facilitating at least one of input, processing, and output. Often, small units of hardware, such as buttons, wires, and lights contribute to larger units of hardware called devices. Likewise these devices also facilitate Input, Processing, and Output. So, to use the same example from before, the NES controller is an Input Device, the NES is a Processing Device, and the attached display is an Output Device.   

Human Input Device
A Human Input Device (or HID, for short) is a name we call Input devices that are designed to interface with a human in some way. The most common method is hand manipulation
